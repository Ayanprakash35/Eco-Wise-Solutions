# Eco-Wise Solutions

A website about plastic pollution and practical ways to cut down on single-use plastic, made for a Design project.

**[Live demo →](https://ayanprakash35.github.io/Eco-Wise-Solutions/)**

## Features

- Background on the plastic pollution problem
- Everyday alternatives: reusable bags, metal straws, glass bottles
- A quick quiz: *How plastic-free is your lifestyle?*
- Success stories from Mumbai beach cleanups, plastic roads in India and coral restoration in the Maldives

## Built with

HTML and CSS

## Run it locally

Clone the repo and open `index.html` in a browser.
